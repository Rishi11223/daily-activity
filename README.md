# Daily Activity

Auto-generated daily commits to keep the contribution graph green.

## How it works

A GitHub Actions workflow runs daily, appends a random fact with a timestamp to `log.md`, and commits it back to the repo.

## Setup

1. Create a [GitHub Personal Access Token](https://github.com/settings/tokens) with `repo` scope
2. Add it as a repository secret named `PAT`
3. The workflow will run automatically every day
